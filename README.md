# story-booth

A web app that records users answering 5 fixed questions about family. Users grant
camera/mic access → press "Start" → record one continuous video while questions auto-advance
every ~60s → upload a single file at the end.

## Stack
- Next.js (App Router) + TypeScript + Tailwind CSS
- Recording: MediaRecorder API (.webm)
- Storage: Cloudinary (via a storage adapter — swappable to Google Drive)
- Deploy: Vercel (free, HTTPS)

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

> Camera/mic only work over HTTPS or localhost.

## Configuration
Create `.env.local` (see `.env.example`):
```
NEXT_PUBLIC_STORAGE_PROVIDER=cloudinary
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=...
NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET=...
```
